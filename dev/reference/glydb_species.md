# Get Supported Species From Glydb Data

Get a character vector of supported species from
[glydb_data](https://glycoverse.github.io/glydb/dev/reference/glydb_data.md).

## Usage

``` r
glydb_species()
```

## Value

A character vector of supported species.

## Examples

``` r
glydb_species()
#>  [1] "Saccharomyces cerevisiae"                       
#>  [2] "Mus musculus"

#>  [5] "Bos taurus"                                     
#>  [6] "Gallus gallus"                                  
#>  [7] "Drosophila melanogaster"                        
#>  [8] "Cricetulus griseus"                             
#>  [9] "Homo sapiens"                                   
#> [10] "Sus scrofa"                                     
#> [11] "Sus scrofa domesticus"                          
#> [12] "Severe acute respiratory syndrome coronavirus 2"
#> [13] "Danio rerio"                                    
#> [14] "Arabidopsis thaliana"                           
#> [15] "Dictyostelium discoideum"
```
